## ⚠️ App not working: Gemini API Key required

### Problem Description
The app installs and starts successfully, but it currently cannot be used (requests are not answered or the app crashes).

### Cause
A valid **Google Gemini API Key** is required for **JarvisAI** to function. Without this key, AI requests cannot be processed.

### Proposed Solution / To-Do
- [ ] Add an input field in the app settings where the user can enter their own Gemini API Key.
- [ ] Alternatively, configure the API key in the project's configuration files before building.

---
*Note: A free API key can be generated in [Google AI Studio](https://aistudio.google.com/).*
